=> goroutines : 
   one single os thread has many goroutines. Go runtime manages their execution on single os thread. but that os thread 
   itself is managed by os only. context switching b/w os thread is costlier but b/w goroutines is cheaper. 
   stack size of goroutines : 2 kb , os thread : 8 MB
